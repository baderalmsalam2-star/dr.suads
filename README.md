# منصة التدريس

منصة عرض حصص **مقرر الولاية والوكالة والوصاية** — د. سعاد المطوع.

صفحات ثابتة (HTML/CSS/JS) بلا أي اعتماديات ولا خطوة بناء. تُفتح مباشرةً من
القرص بالضغط على `index.html`، أو تُنشر كما هي على أي استضافة ثابتة.

## البنية

```
index.html                        الصفحة الرئيسية: اختيار الشعبة وقائمة الحصص
data/course.js                    ← الملف الوحيد الذي يُعدَّل عادةً
assets/tokens.css                 ألوان الجامعة والخطوط
assets/platform.css               أنماط الصفحة الرئيسية
assets/platform.js                بناء قائمة الحصص
assets/deck.css                   أنماط عرض الحصة
assets/deck.js                    محرّك العرض: التنقل، المؤقت، الجواب، القارئات
sessions/01-tareef-al-wilaya.html الحصة الأولى — تعريف الولاية
```

المحرّك والأنماط مشتركة، فملف الحصة لا يحتوي إلا على المحتوى.

## إضافة حصة جديدة

1. انسخ `sessions/01-tareef-al-wilaya.html` باسم جديد.
2. غيِّر `<title>` و `data-session` في وسم `<body>` إلى رقم الحصة.
3. استبدل الأقسام `<section class="slide">` بمحتوى الحصة الجديدة.
4. أضف الحصة إلى `sessions` في `data/course.js` واجعل `status: "ready"`.

لا شيء غير ذلك — الشريط العلوي والقارئات والمؤقت والفهرس تُبنى تلقائيًا.

### وسوم الشرائح

| الوسم | أثره |
|---|---|
| `data-tab="…"` | نص اللسان الأصفر أعلى الإطار |
| `data-src="…"` | المصدر أو رقم الصفحة في الشريط العلوي |
| `data-reader` | شريحة قراءة — يُسنَد إليها رقم طالبة تلقائيًا |
| `data-timer="30"` | يبدأ مؤقتًا بعدد الثواني عند ظهور الشريحة |
| `data-q` | شريحة سؤال — مسافة تُظهر الإجابة الصحيحة والتعليق |

داخل شريحة السؤال: `<li class="right">` هو الخيار الصحيح،
و `<div class="answer">` هو التعليق الذي يظهر مع الإجابة.

## الشعب وتوزيع القارئات

الشعب معرَّفة في `data/course.js` مع عدد الطالبات المسجّلات في كل شعبة
(الحد الأقصى ٤٥). يُختار من الصفحة الرئيسية ويُحفظ في المتصفح، ويُمرَّر
إلى الحصة في الرابط:

```
sessions/01-tareef-al-wilaya.html?section=2
```

يقبل الرابط أيضًا `?roster=20` و `?startAt=6` لتجاوز الإعداد مؤقتًا دون
تعديل أي ملف. تُوزَّع القارئات دائريًا: تبدأ الحصة من `startAt` وتلتف
عند تجاوز عدد المسجّلات، فتنتقل الدورة بين الحصص تلقائيًا.

## أثناء الحصة

| المفتاح | الأثر |
|---|---|
| `←` / `PageDown` | الشريحة التالية |
| `→` / `PageUp` | الشريحة السابقة |
| `مسافة` | إظهار الجواب في شرائح الأسئلة |
| `ر` / `r` | إعادة تشغيل المؤقت |
| `Home` / `End` | أول شريحة / آخر شريحة |

النقر على الشاشة ينتقل للتالي (وفي شرائح الأسئلة يُظهر الجواب أولًا)،
والسحب بالإصبع يعمل على الأجهزة اللمسية.

**الطباعة** (`Ctrl/Cmd + P`) تُصدِّر الحصة كاملةً — كل شريحة في صفحة
مع الأجوبة ظاهرة — للتوزيع أو الأرشفة.
